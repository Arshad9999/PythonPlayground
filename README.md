# Python Playground

Small Python exercises for Armstrong numbers, factorials, Fibonacci sequences, prime numbers, and a notebook of printed patterns.

## Setup and usage

Use Python 3. The four scripts use only the standard library.

```sh
python3 ArmstrongNumber.py
python3 FactorialFunction.py
python3 FibonacciSeries.py
python3 PrimeNumbers.py
```

The factorial, Fibonacci, and prime scripts prompt for numeric input. Open `PythonPatterns/BasicPythonPatterns.ipynb` with Jupyter to explore the notebook.
